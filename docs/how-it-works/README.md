# How it works

These pages explain how the app works, in plain words, for a judge, a new teammate or a curious user. The [spec](../../spec/product.md) is different: it is written for the agents that build, and these pages tell the same design to a person. Nothing described here is built yet.

Read them in this order.

| Page | What it covers |
|---|---|
| [capture-to-facts.md](capture-to-facts.md) | How a few photos of an item become a list of facts, each pointing to where it came from. |
| [clarifying-questions.md](clarifying-questions.md) | Why the app sometimes asks you something, and how it picks the one question. |
| `identify-and-similar-items.md` | How the app works out what an item is and finds similar ones, such as cheaper alternatives. |
| `value-and-price-history.md` | How a value range is found from past sales, and how prices are tracked over time. |
| `search-and-shopping.md` | How search, the shopping view, saved lists and referral links work, with or without an account. |
| [selling-runs-itself.md](selling-runs-itself.md) | How one item becomes a listing on each site, and what the app does without asking. |
| [how-we-prove-it.md](how-we-prove-it.md) | Why you can trust a number or message: kept evidence, hidden weak numbers, and checks before sending. |
