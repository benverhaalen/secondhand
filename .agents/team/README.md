Create a small packet only for a useful work claim/handoff, changed dependency, decision, or blocker. Path: `packets/TOPIC/NUMBER-short-name.md` (lowercase, hyphens). Topic is the parent directory; numeric IDs must be unique across all topics. Keep status, owner, branch/base, date, evidence, next action, and interpretations explicit. Change the affected packet when a linked decision changes so manual metadata checks notice it. Git content hashes identify exactly what was read; local acknowledgement is not team agreement.
