## 5. Learned the hard way

- Run the whole area's tests after merging main, not the worker's own list: three of today's merges broke tests outside the workers' files (two `waking` expectations, the watch tests, the proof's pin), and one reached origin before the full check because another session pushed on top of the shared checkout.
- A test that builds a path from `new URL(...).pathname` fails on Windows (`/C:/...`); use `fileURLToPath`.
- J12's cause was not only the pace slot: `search.ts` ports `harness` and `accounts` were never set in the composed product, so Depop and eBay waited their slot and then answered "cloud launcher not configured". Read what the composition root passes before measuring.
- A brief written before a ruling lands can be wrong in its own direction: round 2 of J1 refused unmodellable rows, which MI1 reversed an hour later. When a lead's brief and the orchestrator's later rule disagree, the newer rule wins and the brief says so.
- A one-line scrub over a whole page string blanks a minified page; scrub structure, keep evidence whole.
- Python on Windows rewrites line endings when it rewrites a file; check `git show --stat` after a scripted edit.
