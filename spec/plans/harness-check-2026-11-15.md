## What blocks each gap

- eBay sold comps: sold search needs a signed-in session on every host, and the sold parser has never seen a signed-in page. Ben's harness lead (`sites/ebay`) plus Nate linking one account (SV9). Proof: one recorded signed-in sold read parsed into `SoldRow`s, then eBay added to `SoldSite` with a valuation test.
- Depop sold comps: not wired into the engine. Engines lead (EN6/SV6) plus the search lead. Proof: a sold read on `depop.read_listings` (status sold) returns comps and `soldSources` includes `depop`.
- Poshmark sold comps live: code path ready, never read live. Engines lead. Proof: run with `SECONDHAND_LIVE_SITES=poshmark` for one query and record the comp count.
- Mercari search and sold: needs the person's linked account, and the linked-account search test fails now. That is SV5 (account lookups under the owning person) meeting `mercari/linked.ts` (server lead's packet 86 names it, search lead's file). Proof: `mercari/linked.test.ts` 2/2, then one linked Mercari read.
- Monitor on all four signed-in sites (eBay, Depop, Poshmark, Mercari): no signed-in client is composed (`compose.ts` builds public clients only) and no account is linked. This is SV9 (server lead, Nate links the account). Proof: one real account linked in the live view and a recorded read of inbox, offers, orders and listing interest.
- Manage on those sites: writes are dry by design; Nate ruled the system does not post for a person (`finalization.md` section 3). What remains is a guided handoff, not a live write. Proof, if wanted later: Nate approves one dry plan per verb against his own test listing.
- Analytics: the port serves a fixed example for `usr_8f2k`. Needs `read_stats` and `read_orders` results stored as stats and sales rows and an `AnalyticsPort` that reads them per person. Data and engines leads, after SV9. Proof: `GET /v1/insights` for a linked person returns counts that match a recorded read.
- Facebook (all but search): no adapter. Search needs `APIFY_TOKEN` and the per-day run caps. Monitor, manage and analytics have no route found (`platform.ts:43`). Product call for Nate: Facebook stays search-only until a route is found.
