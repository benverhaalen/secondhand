# Features

One folder per feature, with one living `README.md` in each. The folder name is the feature's slug, and the same slug is used in `research/<person>/<slug>/` and in packet topics. To add a feature, copy any existing page, add a row to [product/features.md](../product/features.md), and run `node .agents/check.mjs`.

A feature page only summarizes and links. Findings stay in research and quotes stay in [words.md](../product/words.md), so a feature page never becomes a third copy that drifts.
