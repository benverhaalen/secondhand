# M1: the first reads on Browser Use Cloud
Researched 2026-11-14 by Nate (build orchestrator).

Owner: Nate. Run 2026-11-14 about 23:10 Central (05:08 to 05:12 UTC on the 15th) by the build orchestrator, from the Windows machine. Every line is *observed* in the command's own output unless marked.

Command, with the key loaded from the user's environment for that one process and never printed:
`node app/src/edge/browser/cloud-read.ts <site> "carhartt jacket"`

It creates a cloud browser (`timeout` 2 minutes, `proxyCountryCode` `us`, `solveCaptchas` false, no profile), connects over CDP, blocks images, media and fonts, opens the site's public search page with no login, reads the listings with the reader in `app/src/edge/intel/public/readers.ts` (no model), and stops the browser.

| Site | HTTP | Connected | Page loaded | Rows read | Browser stopped | Result |
|---|---|---|---|---|---|---|
| Depop | 200 | 0.54 s | 2.47 s | 3.55 s | 3.79 s | 24 listings |
| Poshmark | 200 | 0.50 s | 2.54 s | 3.75 s | 3.90 s | 48 listings |
| Mercari | 200 | 0.52 s | 1.59 s | 6.21 s | 6.39 s | the real search page, no challenge; 0 rows because the reader was written from a hand-built fixture and does not match the live markup (`page_changed`: missing id, price_cents, url) |
| eBay | 403 | 0.48 s | 1.28 s | none | 16.49 s | "Error Page \| eBay": refused on this address too |

What this settles:
- A cloud browser is ready in about half a second from create to connected. The reference note had no cold start figure.
- Depop and Mercari, which answered 403 to headless Chrome on this machine (`bp-1.md`, run 2), answer 200 on a cloud browser.
- Cost: the vendor's session list shows `browserCost` 0.001 for each stopped session, so one read is about a tenth of a cent of browser time. Proxy data is not in that figure.
- Every session shows `stopped` in the vendor's list after the run; none was left running.

Found and fixed by the run:
- Depop marks a reduced listing with "Full price" then "Discounted price"; the reader only knew "Price" and failed the whole page. It now reads the discounted price, with a test.
- A refused page (eBay's 403) parsed to zero rows and was reported as an empty result. The command now reports `blocked` for any status of 400 or more. The same rule belongs in the kernel's public lane (*inferred*; not yet checked there).

Not done:
- Mercari's reader is not rewritten from the live page.
- eBay's public search needs another route. eBay publishes an official Browse API for public listing search; that is the next thing to try for this one site (*agent proposal*).
- Facebook Marketplace was not run.
- `bytes_declared` is the sum of `content-length` headers, which many responses omit, so it is a floor and not the proxy bill.
- This run is not reviewed by a seat that did not write it, so M1 is not ticked on the board.
