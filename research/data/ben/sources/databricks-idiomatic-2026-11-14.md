### The end-to-end pattern staff show (observed, agentic-support-console)
OLTP writes to Lakebase, then Lakebase CDF into UC bronze CDC history tables, then a Lakeflow Spark Declarative Pipeline builds silver current-state and gold materialised views, then a Lakeflow Job (every minute) finds unanswered rows, builds context from gold, calls a serving endpoint, merges suggestions into a Delta table, then reverse synced tables push gold back to Lakebase for ms reads, and a Genie Agent sits on gold. The app has the human approve/edit/override the AI suggestion. Source: https://developers.databricks.com/templates/agentic-support-console.md and repo dir `agentic-support-console/`. This is the answer to "is Delta/Spark doing work": the gold tables feed both the app (via reverse sync) and Genie. The team's data.md already matches this shape. Inferred: the missing piece in data.md vs. the template is the explicit medallion pipeline for comps and a scheduled "suggest" job.
- Content-moderator README: register the Lakebase database as a UC catalog (`databricks postgres create-catalog <name> ...`) so SQL warehouse, dashboards and Genie can read Lakebase directly; the catalog name is load-bearing for AppKit type generation; app service principal seeds the schema at first startup; AI scoring calls `databricks-gpt-5-4-mini` via the app service principal. Source: cloned `content-moderator/README.md` (observed 2026-11-14).

### Evaluation and "money shots" (inferred from what the templates ship; no DAIS 2026 talk video was watched)
- Agent templates ship `evaluate_agent.py` using `ConversationSimulator`, `Safety`, `ToolCallCorrectness`, `Completeness`, `UserFrustration` etc., and the README says "open the MLflow UI link for your experiment to inspect results" (observed, cloned repo). So the staff-standard visual is: trace tree in MLflow, then an evaluation run table of scorer scores.
- Judge alignment: `make_judge`, `mlflow.log_feedback(name == judge name)`, `judge.align(traces)` (MemAlign default, SIMBA/GEPA optional), then `.register`. Needs MLflow >= 3.14.0, at least 10 traces, 50-100 recommended, at least 30% negative; docs claim 30-50% better agreement with humans (asserted, vendor figure). Not supported for agent-based, expectation-based, or multi-turn judges. Source: https://docs.databricks.com/aws/en/mlflow3/genai/eval-monitor/align-judges (observed). Mapping to the app: a user's approve/edit tap is the human feedback; "judge agreement before vs after alignment" is a before/after score the team can show. Inferred, not tested.
- Human feedback docs: Traces tab > Assess > Add expectation > Add to dataset; review queues Beta. https://docs.databricks.com/aws/en/mlflow3/genai/human-feedback/ (observed).
- Production monitoring: same scorers on live traffic (observed, eval-monitor overview page). Stage not stated.
- Trace storage: UC Delta tables recommended, direct SQL; Nov 2 2026 "Managed warehouse for MLflow" (Beta) lets you view UC traces without choosing a warehouse (observed, Nov release notes). The team's note that `logFeedback` does not cover UC-stored traces was not re-checked.
- DAIS 2026 coverage I could reach (Atlan, Qubika, fullstack recaps) lists announcements, not demos. I found no source describing a staff demo's "money shot". Lakebase branching and snapshots (GA, expanded) and Genie Ontology were the headline items (asserted, secondary recaps). Treat money-shot ranking as inferred.

### Free Edition and platform gotchas
1. Outbound internet on Free Edition: "restricted to a limited set of trusted domains" and no published list (observed, limitations page and community thread 2026-02-02 where a Databricks employee agreed). pypi.org works; wikipedia.org blocked in US region, allowed in EU (anecdote, thread). Neither doc nor thread says whether Apps are covered. Official Apps egress controls (NCC, network policies) are Enterprise tier only (observed, Apps networking doc). Unknown: whether Apps on Free can reach api.openai.com, eBay, Exa, etc. Test with `curl -v` from an app on day zero. A community thread says external-model endpoints (e.g. OpenAI) worked in a 2025 Free workspace (asserted, user report).
2. FMAPI on Free Edition: unresolved. 2025 threads: pay-per-token returned PERMISSION_DENIED "not allowed to be used by your workspace"; serving endpoints needed provisioned throughput; no success reported from Apps. https://community.databricks.com/t5/databricks-free-edition-help/not-able-to-serve-or-interact-with-llms-in-databricks-free/m-p/121952 (observed; Jun-Dec 2025, no staff reply). Aug 2026 thread on a paid workspace: `databricks-claude-sonnet-5` returned 403 "Databricks-set rate limit of 0"; a non-staff reply said Llama works (unverified). https://community.databricks.com/t5/generative-ai/databricks-hosted-foundation-model-apis-blocked-by-workspace/td-p/166270. Free Edition docs say you can "try foundation models" but name no models. Inferred: premium Claude/GPT may be rate-limit 0 on Free; Llama 4 Maverick / GPT OSS / Gemma are the likely working set; verify in the Playground.
3. Apps request timeout: community says about 2 minutes hard (some report about 30 s idle, stream frozen at 120 s); employee reply says it cannot be raised; use start-then-poll. Not in official docs I could read. (asserted, forum, 2025-2026). The advanced agent templates build this in: background mode, poll, resume stream (observed, `agent-openai-advanced/README.md`), and set `CHAT_PROXY_TIMEOUT_SECONDS=300`.
4. Apps auth: app service principal is per app, not replaceable; all users share its permissions. User authorization (OBO) forwards `x-forwarded-access-token`, needs declared scopes (`sql`, `genie`, `files`, etc.), works only within the app's workspace; defaults expose no data. Community report that the forwarded token expired and forced a redeploy, no fix given (asserted). Docs: https://docs.databricks.com/aws/en/dev-tools/databricks-apps/auth. AppKit OBO: missing user token returns 401, no fallback to SP; the model adapter must use the per-request client or the app fails at startup (observed, agentic-features page).
5. Lakebase from Apps: add Database resource with "Can connect and create"; Databricks creates a Postgres role named for the SP client ID; env vars `PGHOST` etc.; do not rename the resource key `database` to `postgres` (separate roles, loses access to existing data); provisioned instances cannot be created after 2026-03-12 so use Autoscaling (observed). OAuth tokens last 1 hour and expiry is checked at connection open; AppKit `lakebase()` refreshes for hosted apps; hand-rolled apps need pool refresh and psycopg3 async pooling (asserted, DAIS session by Irvin Umana, Databricks Lead Scale SE). Scale to zero: Free has one project, scale-to-zero.
6. Deploy gotchas (observed, agent template README): "app with the same name already exists" means `databricks bundle deployment bind`; `bundle deploy` does not restart, run `databricks bundle run <app>`; 302 on querying an agent means use OAuth (PATs not supported); deleting an app destroys its SP and orphans Lakebase schemas (lakebase-for-ai-developers README). Apps must exit within 15 s of SIGTERM, bind `DATABRICKS_APP_PORT`, keep startup light (observed, best-practices page). Default 2 vCPU / 6 GB (observed).
7. Unity Gateway / endpoint naming: `databricks-` hosted endpoints are marked Legacy in the Apps resource picker, with Unity Gateway model services (`system.ai.<model>`) the new path (observed, agentic-features page). Templates still use `databricks-claude-sonnet-5-5` and `databricks-gpt-5-4-mini` as endpoint names (observed in cloned repo); both forms work as of the repo date.
8. Deprecated or legacy: Knowledge Assistant and Supervisor Agent are legacy since Oct 12 2026 (observed); Knowledge Assistant is also unsupported on Free Edition (brief). AppKit `serving()` plugin deprecated at 0.77.0; inline `agents` map deprecated at 0.64.0. AI Functions on runtimes below 17.3 LTS end Feb 1 2027 (observed). DeepSeek V4.1 Flash retires Nov 19 2026; Gemini 3.6 Flash retires Nov 19 (observed, release notes), so do not pin those for a demo.
9. Managed MCP: workspace endpoints (Genie Agent, AI Search, UC functions) are Public Preview and need an admin to enable "Managed MCP Servers" on Previews; Genie One MCP GA; `dbsql`, `web_search`, `sandbox` Beta and need Enhanced Unity Gateway (observed). On Free Edition you are your own admin, so these toggles may be reachable; not verified.
10. Genie Conversation API: poll 1-5 s with backoff, stop after about 10 min, new conversation per session, no automatic retries, 200k conversations per agent (observed). Matches data.md.
