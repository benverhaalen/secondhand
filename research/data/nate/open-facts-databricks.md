# Which Databricks facts were still unknown or only believed, and what does the official documentation say?
Researched 2026-11-14 by Nate (Claude Code retriever, Sonnet 5.5). Feature: data.

All URLs are under `https://docs.databricks.com/aws/en/` unless written in full. "Page date" is the "Last updated" line on the page. Earlier note: [databricks-platform.md](databricks-platform.md). Where I say "not stated", the page text I opened has no such statement; that does not prove the fact is absent. Products have been renamed in these docs: Vector Search is "AI Search", Delta Sharing is "OpenSharing", the AI Gateway pages are "Unity Gateway", Lakehouse Monitoring is "Data profiling".

## 1. Delta row tracking, and linking a derived value to source rows
Partly. Row tracking gives each row a stable id (`_metadata.row_id`, stable across MERGE and UPDATE) and a `_metadata.row_commit_version`, enabled with `delta.enableRowTracking = true`, DBR 14.0+; the page describes it as "enabling row-level lineage tracking" (*observed*, `delta/row-tracking`, page date Sep 11, 2026). Limits (*observed*, same page): it upgrades the writer protocol and can break external Delta clients, enabling on an existing table can be slow and fails concurrent writers, a clone gets different ids, the fields are not readable through change data feed. No feature that records "this derived value came from these source rows" was found (*not found*; the closest is storing `row_id` yourself, *inferred*). Release status and Free Edition: not stated on the page.

## 2. Unity Catalog lineage granularity; volumes and model inputs
Yes to column level for tables; partly for files and models. Lineage is captured automatically down to column level and its nodes include tables, views, columns, ML model versions, file paths, notebooks, jobs, pipelines, queries, dashboards; model services through Unity Gateway are covered (*observed*, `data-governance/unity-catalog/data-lineage`, Nov 4, 2026). UDF lineage is table-level only; column lineage is not shown in Catalog Explorer for path-referenced sources, but `system.access.column_lineage` records `source_path` or `target_path`; lineage is lost on rename; Catalog Explorer view is kept indefinitely from Sep 1, 2024 and system tables keep a rolling 395 days (*observed*, same page). Lineage system table `admin/system-tables/lineage` (Nov 4, 2026) has no table-version field (*observed*). Files inside a volume specifically, and the model-lineage sub-page, were not confirmed (*not found*).

## 3. Metric views: validity or suppression condition on a measure
No. A measure has only `name`, `expr`, `comment`, `display_name`, `format`, `synonyms`, `window`; no validity, minimum-count, suppression or freshness field (*observed*, `uc-semantics/metric-views/yaml-reference`, Oct 28, 2026, and `uc-semantics/metric-views/`, Oct 29, 2026). Closest: a view-level `filter`, filtered measures (`SUM(...) FILTER (WHERE ...)`), and conditional logic inside `expr` such as CASE returning NULL (*inferred*). Relationships are Beta; ABAC cannot be applied to metric views (*observed*). Free Edition: not stated.

## 4. Governed tags and ABAC
Status is mixed. Row filter and column mask policies (UDF based, catalog, schema or table scope, DBR 16.4+ or serverless) are the baseline; metastore scope, ABAC on views, identity attributes, context attributes, DENY policies, and agent services and skills are Beta (*observed*, `data-governance/unity-catalog/abac/`, Oct 22, 2026; `abac/policies`, Oct 15; `abac/core-concepts`, Oct 29; `abac/requirements`, Nov 4). GRANT-type policies cover models, model services, model provider services and MCP services (*observed*, same pages). No policy type blocks a table from model training, serving or sharing (*not found*). Governed tags are account level; tags inherit from catalog and schema to children but not from table to column; propagation through lineage was not found (*observed* for inheritance, `admin/governed-tags/` and `database-objects/tags`, Nov 11, 2026; *not found* for lineage). Interactions: ABAC on a source table does not apply to AI Search indexes built from it; clones of ABAC tables need an EXCEPT principal; an OpenSharing share of an ABAC table works only if the share owner is exempt (*observed*, ABAC pages). Limits: 10,000 policies per metastore, 100 per catalog or schema, 50 per table (*observed*). Free Edition: not stated.

## 5. Time travel, retention, recording and replaying a query's table versions
Time travel yes; recording and replay of the versions a query read: no (*not found*). `logRetentionDuration` defaults to 30 days and `deletedFileRetentionDuration` to 7 days; DBR 18.0+ blocks time travel older than `deletedFileRetentionDuration`, so readable history is 7 days by default, not 30 (*observed*, `delta/history`, Nov 6, 2026). RESTORE and in-commit timestamps exist (*observed*). The query-history and lineage system tables carry no table-version field (*not found*). Recording the version yourself with `DESCRIBE HISTORY` at query time is possible (*inferred*).

## 6. Gateway guardrails
Four built-in policies, plus custom ones, all in Beta. Built-ins: `system.ai.block_unsafe_content`, `system.ai.block_jailbreak` (input on model services), `system.ai.block_hallucination` (output), `system.ai.detect_sensitive_data` (deterministic pattern checks such as credit card and SSN, deny or mask) (*observed*, `ai-gateway/`, Nov 13, 2026; `data-governance/unity-catalog/service-policies/`, Nov 13, 2026, Beta). No sub-category list inside "unsafe content" was found (*not found*). Decisions are ALLOW, DENY, ASK at phases ON CALL and ON RESULT; a DENY returns HTTP 200 with a `databricks_service_policy` object (*observed*). Custom: a SQL UDF, an LLM-as-a-judge with natural-language criteria, or an external vendor policy through an HTTP connection with OAuth M2M only (*observed*). Free Edition: not stated.

## 7. MLflow 3 tracing, pre-release scoring, judges, human feedback, datasets
- OpenTelemetry ingestion: yes. Third-party OTLP clients post protobuf to `https://<workspace>/api/2.0/otel/v1/traces` with header `X-Databricks-UC-Table-Name`; spans land in UC tables `<prefix>_otel_spans`, `_otel_logs`, `_otel_metrics`, `_otel_annotations`; traces need a root span; experiment storage caps at 100,000 traces; MODIFY and SELECT on each table are required (*observed*, `mlflow3/genai/tracing/trace-unity-catalog`, Nov 12, 2026). The managed warehouse option is Beta there. The general Zerobus OTLP page covers traces, logs, metrics over gRPC and HTTP protobuf, JSON rejected, 10,000 requests per second default quota, header `x-databricks-zerobus-table-name` (*observed*, `ingestion/opentelemetry/`, Nov 12, 2026). Self-hosted MLflow's own endpoint is `/v1/traces` with `x-mlflow-experiment-id`, MLflow 3.6.0+ (*observed*, `https://mlflow.org/docs/latest/genai/tracing/opentelemetry/ingest/`, undated).
- Scorer that runs before a response is released: no (*not found*). Production monitoring scores a sample of already-logged traces, Beta, with `sample_rate` up to 1.0 (*observed*, `mlflow3/genai/eval-monitor/production-monitoring`, Oct 9, 2026); it is asynchronous, so it does not gate release (*inferred*). The closest pre-release check is a Unity Gateway service policy at ON RESULT (Q6).
- Judges: RetrievalGroundedness ("Is the response grounded in the information provided in the context? Is the agent hallucinating?", no ground truth) and Correctness (needs `expectations` ground truth) are built in, along with RelevanceToQuery, RetrievalRelevance, Safety, RetrievalSufficiency, Guidelines, ExpectationsGuidelines, ToolCallCorrectness, ToolCallEfficiency and multi-turn judges (*observed*, `mlflow3/genai/eval-monitor/concepts/judges/`, Sep 15, 2026).
- Human feedback: yes, `mlflow.log_feedback()` and `mlflow.log_expectation()` with `AssessmentSource(source_type=HUMAN)`; expert labelling through the Review App; review queues are Beta (*observed*, `mlflow3/genai/human-feedback/dev-annotations`, Oct 9, 2026). Labelling-schema and review-queue sub-pages: unopened.
- Evaluation datasets: yes, `mlflow.genai.datasets.create_dataset`, `get_dataset`, `.merge_records`, stored in UC tables; 2000 rows per dataset, 20 expectations per record, not in CMK-encrypted catalogs (*observed*, `mlflow3/genai/eval-monitor/build-eval-dataset`, Oct 9, 2026).
Free Edition: not stated for any of these.

## 8. Databricks Apps: timeout, SSE, websockets, background work, cold start, sizes
Sizes are documented; timeout, SSE and websockets are not. Medium up to 2 vCPU / 6 GB / 0.5 DBU per hour (default); Large 4 vCPU / 12 GB / 1 DBU per hour; XLarge 12 vCPU / 48 GB / 3 DBU per hour in some regions (*observed*, `dev-tools/databricks-apps/compute-size`, Nov 12, 2026). Horizontal scaling 1 to 5 instances, 20 scaled apps per workspace, best-effort session affinity by cookie (*observed*, `.../horizontal-scaling`, Nov 12, 2026); 100 apps per workspace (*observed*, `resources/limits`, Nov 13, 2026). SIGTERM then SIGKILL after 15 s; proxy needs HTTP/2 cleartext; docs say to minimise startup time for cold start (no number) and to use asynchronous patterns because synchronous requests "can time out" (no number) (*observed*, `.../best-practices`). The words websocket and SSE appear on none of the Apps pages I opened (*not found*). Background work is not a documented feature; the documented advice is start-then-poll (*observed*). Forum and third-party figures disagree, so they are *asserted* only: about 2 minutes (community thread 146746, Feb 2026), about 30 seconds (thread 149966, Mar 2026), 120 s (a third-party guide, Jun 10, 2026). Free Edition: up to 3 apps, each stopped automatically 24 hours after start, update or redeploy (*observed*, `getting-started/free-edition-limitations`, Oct 18, 2026).

## 9. Lakebase
- Branching: yes, copy-on-write, instant reset from parent, point-in-time branches; branches can expire with a TTL of at most 30 days (extendable); default and protected branches and parents of children cannot expire (*observed*, `oltp/projects/branches`, Oct 30, 2026, and `oltp/projects/manage-branches`, page date not recorded). 500 branches per project, 20 concurrently active computes per project, 6 read replicas per branch, 500 roles and 500 databases per branch (*observed*, `oltp/projects/manage-projects`).
- Compute ceiling, resolving the 112 vs 64 disagreement in the earlier note: both are true. Autoscaling computes run 0.5 to 64 CU; fixed-size computes go 65 to 112 CU; autoscale range max minus min is at most 16 CU (*observed*, `oltp/projects/manage-computes`, Nov 4, 2026).
- Connection limits: a table by size, for example 0.5 CU 105, 1 CU 218, 2 CU 443, 8 CU 1795, and 3993 from 24 CU upward; with autoscaling the limit is that of the smaller of the max CU and 8 times the min CU (*observed*, same page).
- Row-level security with an app-set session variable: not documented. The Data API page says RLS is standard Postgres RLS, enabled per table, with BYPASSRLS roles and table owners exempt, and identity is the Databricks OAuth identity mapped to a Postgres role (*observed*, `oltp/projects/data-api`, Nov 2, 2026). A policy on `current_setting(...)` is ordinary Postgres and likely works (*inferred*; no Lakebase page mentions `set_config` or `current_setting`).
- Data API: PostgREST-compatible, OAuth bearer token required; no Beta or GA label on the page (*not found* for stage). Free Edition: one Lakebase project per account with scale-to-zero compute (*observed*, free-edition page).

## 10. AI Search: image or multimodal, hybrid, Free Edition endpoint
Hybrid keyword-similarity search: yes (*observed*, `ai-search/ai-search`, Oct 29, 2026). Full-text search and dedicated full-text indexes are Beta (*observed*, same page). Image or multimodal indexes: no dedicated feature found; the page says embeddings are "typically text or image data" in general terms only, and documents no image index type (*not found*; the closest is embedding images yourself and using a self-managed index, *inferred*). Free Edition: one AI Search endpoint limited to one search unit, Direct Vector Access unsupported (*observed*, `getting-started/free-edition-limitations`, Oct 18, 2026).

## 11. Model serving and gateway: external providers, Claude, Free Edition, image input
External providers: yes. Model provider services support OpenAI, Azure OpenAI, Anthropic (API key, or each caller's own Claude subscription), Amazon Bedrock, Bedrock Mantle, Microsoft Foundry, Google Gemini Enterprise and Custom (*observed*, `ai-gateway/model-provider-services`, Nov 12, 2026). Custom model services can mix Databricks-served and external models and take service rate limits (*observed*, `ai-gateway/model-services`, Nov 12, 2026). Databricks-hosted Claude includes Opus 5.5, Haiku 5.5, Sonnet 5.5, Sonnet 5, Fable 5.2 and others (*observed*, `machine-learning/foundation-model-apis/supported-models`, Nov 13, 2026). Image input per page: Opus 5.5, Haiku 5.5 and Haiku 4.5, Sonnet 5, Sonnet 4.6, Fable 5.2 and 5.1 accept text and image; Sonnet 5.5 and Fable 5 are listed text-only (*observed*, same page). Free Edition: external endpoints are not addressed directly; the page says outbound internet access is limited to a set of trusted domains, and lists no GPU endpoints, no provisioned throughput, and "certain models not available" (*observed*, free-edition page). Whether a Free Edition workspace can reach api.anthropic.com is therefore *not found*. Per-model rate limits are on a separate "rate limits by model" page, unopened.

## 12. Genie: API from an app for non-workspace users, rate limits
Partly. The Genie Agents API supports OAuth U2M for users with a browser and a service principal (OAuth M2M) otherwise; data access is checked against each end user's UC permissions in the normal path (*observed*, `genie/conversation-api`, Nov 5, 2026, and `genie/set-up`). A way to serve end users with no workspace identity is not described beyond the service-principal route (*not found*). Rate limits are not given; the page says to poll every 1 to 5 seconds for up to 10 minutes, add your own retry with exponential backoff, and respect 200,000 conversations per agent and 10,000 messages per conversation, 50 tables or views per agent (*observed*). Requires a pro or serverless SQL warehouse and partner-powered AI features enabled (*observed*). Free Edition: not stated.

## 13. File-arrival triggers on volumes; upload from outside the workspace
Triggers: yes on UC volumes and external locations; best effort check every minute, faster with file events enabled on an external location; only new files trigger (an overwrite does not); minimum time between triggers and wait-after-last-change are configurable; a SQL condition on triggers is Beta (*observed*, `jobs/file-arrival-triggers`, Nov 6, 2026). Upload from outside: Files API `PUT /api/2.0/fs/files{path}` up to 5 GiB (Public Preview) and Files API 3.0 up to 5000 MiB single request with multipart upload, Beta, needing the workspace admin to enable a preview and a regional hostname (*observed*, `https://docs.databricks.com/api/files/v2/upload-file.md` and `https://docs.databricks.com/api/files/v3/file`, both undated, and `volumes/volume-files`, found via search, dated Mar 31, 2026 in the index and not re-fetched for its on-page date). Both use a bearer token. Presigned URL upload to a volume: not found in any page opened (*not found*). Free Edition: volumes not stated either way on the limitations page.

## 14. OpenSharing, Marketplace, Clean Rooms from Free Edition
Clean Rooms: no, listed as unsupported on Free Edition (*observed*, `getting-started/free-edition-limitations`, Oct 18, 2026). Marketplace provider: no, "Free Edition accounts cannot become Databricks Marketplace providers" (*observed*, same page). Marketplace in general: provider application via the Data Partner Program, or self-service for private exchanges (*observed*, `marketplace/`, Sep 11, 2026). OpenSharing (Delta Sharing renamed): three protocols, Databricks-to-Databricks (supports volumes, models, notebooks), Databricks-to-Open (tables, any platform) and open-source server (*observed*, `delta-sharing/`, Oct 27, 2026). Whether a Free Edition workspace can create shares is not stated (*not found*). Clean rooms: ten collaborators each; Genie Clean Rooms are Beta (*observed*, `clean-rooms/`, Nov 4, 2026).

## 15. Data quality and monitoring: drift on a table and on a served model
Yes to both, through data profiling (formerly Lakehouse Monitoring). Profiles come as time series, inference and snapshot; a baseline table measures drift; for models, the profile attaches to an inference table of inputs and predictions (*observed*, `lakehouse-monitoring/` content at `data-quality-monitoring/`, Sep 11, 2026, and the data profiling page, Sep 11, 2026). Anomaly detection monitors freshness and completeness per schema (*observed*). Runs on serverless compute, billed as DATA_QUALITY_MONITORING (*observed*). Release status and Free Edition: not stated on the pages; `resources/limits` lists 10 data profiling monitors per the earlier note (*asserted*, from memory of the limits page, not re-checked).

## Earlier claims this changes
- Guardrails (earlier "not found"): answered, Beta service policies with four built-ins and custom SQL, LLM-judge and vendor policies.
- Time travel: readable history is 7 days by default, not 30 (30 is log retention).
- Lakebase CU ceiling: 64 for autoscaling, 112 for fixed size.
- Apps: sizes and horizontal scaling confirmed; the "120 s hard timeout" in [databricks-platform.md](databricks-platform.md) remains forum-only; websockets and SSE still absent from official pages.
- AI Search: ignores ABAC on the source table; no image index.
- Clean Rooms and Marketplace provider: ruled out on Free Edition.
- MLflow on Databricks: OTLP endpoint is `/api/2.0/otel/v1/traces` with a UC table header, not the OSS `/v1/traces`.

## Not found
- Any scorer or guardrail in MLflow that blocks a response before release (only Unity Gateway policies).
- Official figure for Apps request timeout, SSE, websockets, cold start number.
- Metric view validity or suppression field.
- A feature recording the table versions a query read.
- Presigned URL upload to a volume.
- Image or multimodal AI Search index.
- Genie rate limits; Genie access for users with no workspace identity.
- Lakebase RLS with an app-set session variable (documented), Data API stage label.
- Free Edition: external provider reach, share creation, volumes.
- Tag propagation through lineage; per-category list of unsafe-content blocking.
