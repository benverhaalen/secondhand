# Camera and Buy mocks, in code

The source for the camera and the Buy tab, built from [tokens.css](../../tokens.css) and [round 11's parts](../round-11/mock/README.md). What each shows, the renders and what the checkers flag are with the features: [camera](../../../features/capture/design/round-2/README.md), [Buy](../../../features/buy/design/round-2/README.md).

| File | Holds |
|---|---|
| `camera/camera.html`, `camera/camera.css` | The camera over the photos in `features/capture/design/feed/`. The values at the top of the CSS are the camera motion preview's |
| `buy/buy.html`, `buy/buy.css` | The Buy tab over the demo photos in `assets/demo-items/` |
| `*/icons.js` | The Hugeicons each page adds to round 11's set (MIT), made by a script from `@hugeicons/core-free-icons` |
| `fonts.local.css` | Not in git. The same three `@font-face` rules round 11 uses |
