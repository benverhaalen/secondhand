# Hand sprites

Stop-motion hand animations for the website, made by the Codex CLI on 2026-11-15. Each one starts from `base.svg`: the four-finger-03 icon from Hugeicons' free Stroke Rounded set (MIT licence).

- **dap** (`dap/`, `dap.svg`): two hands slide in from the sides, meet palm to palm, bump, and part. 8 frames, 48 by 24.
- **wave** (`wave/`, `wave.svg`): one hand rocks side to side from the wrist, with two short motion marks. 6 frames, 24 by 24.
- **pull** (`pull/`, `pull.svg`): one hand grips a price tag on a string and tugs it down twice. 8 frames, 24 by 24.

Each strip holds its frames side by side, so CSS can step through it with `steps(N)`. Each `NAME-sheet.png` shows the frames at 96 px on white.
