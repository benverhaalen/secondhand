# brand/

The secondhand brand, in the ui-factory form. Status: round 1, provisional; Ben picks on the [brand board](https://claude.ai/artifact/95hea28zWVkFy9afpMZfY8).

- `codes.md`: the signature assets and their boundaries
- `tokens.css`: the only place values live
- `coder-card.md`: read before any UI edit
- `image-card.md`: what the image model is given
- `anti-pillars.md`: banned defaults and what to use instead
- `explore/round-1/`: GPT Image showcases and their inputs

Fonts are licensed (Clofie: free personal-use Regular only; the commercial family with SemiBold is sold by Dealita Studio. Neue Montreal: Pangram Pangram) and are not committed to this public repo.
